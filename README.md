# Loan Approval Prediction

## Overview

This project predicts whether a loan application will be approved or rejected using Machine Learning techniques.

## Problem Statement

Banks receive thousands of loan applications. The objective of this project is to build a predictive model that can determine loan approval status based on applicant information.

## Dataset Features

* Gender
* Married
* Dependents
* Education
* Self Employed
* Applicant Income
* Coapplicant Income
* Loan Amount
* Loan Amount Term
* Credit History
* Property Area

## Workflow

1. Data Cleaning
2. Missing Value Handling
3. Feature Encoding
4. Exploratory Data Analysis (EDA)
5. Model Training
6. Model Evaluation

## Models Used

### Logistic Regression

Accuracy: 82.5%

### Decision Tree

Accuracy: 69.17%

## Key Findings

* Credit History was the most influential factor affecting loan approval.
* Applicants with a positive credit history had significantly higher approval rates.
* Logistic Regression outperformed Decision Tree on the test dataset.
